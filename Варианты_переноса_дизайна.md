# Перенос нового оформления (Главная_1) на старую структуру (Главная_0)

**Задача:** «натянуть» цвета и стиль нового сайта на старый сайт, не меняя структуру и функционал.

**Исходные данные:**
- `Главная_0.html` — действующий дизайн belstat.gov.by (зелёная тема, текстурная шапка, Tahoma, slick-слайдеры);
- `Главная_1.html` — новый дизайн (бирюзовая палитра, плоские компоненты, fill-button, кастомные селекты, swiper, семантическая разметка header/main/site-footer).

Общий для всех вариантов принцип: старый HTML и вся логика остаются нетронутыми, поверх подключается **один дополнительный CSS-файл** (последним в списке стилей). Откат — удаление одной строки подключения.

## Токены нового дизайна (извлечены из Главная_1)

| Назначение | Старый дизайн | Новый дизайн |
|---|---|---|
| Основной цвет | `#006100` / `#30892a` (зелёный) | `#0c9c8e` (бирюзовый) |
| Яркий / hover | `#459044` | `#1ebdad` |
| Светлый акцент | `#d6e78b` (жёлто-зелёный) | `#62d9cd` |
| Тёмный | `#197019` | `#007a7a` |
| Красный акцент | `#a30021` | `#9d0a0f` |
| Фон страницы | `#e9ffe3` | светлый нейтральный (`#f2f8f7`) |

## Вариант 1 — «Палитра» (минимальный)

**Файл:** `demo/variant1-palette.css` (~90 строк)
**Демо:** `demo/variant1.html`

Только замена цветовых токенов через CSS-переменные и точечные переопределения: фон страницы, шапка, меню, ссылки, кнопки (контур), ховеры новостей, стрелки слайдеров, календарь, футер. Сетка, шрифты, скругления, текстуры — как в старом сайте.

- Дешевле всех: 1–2 дня с тестированием, минимальный риск сломать вёрстку;
- Легко откатить, легко поддерживать (все цвета — в `:root`);
- Минус: сайт выглядит как «старый, но перекрашенный» — текстурная шапка и «тяжёлый» стиль никуда не деваются.

## Вариант 2 — «Палитра + компоненты» (средний, рекомендуемый)

**Файл:** `demo/variant2-components.css` (~200 строк)
**Демо:** `demo/variant2.html`

Всё из варианта 1 плюс характерные приёмы нового дизайна на уровне CSS:
- плоская шапка и футер **без зелёной текстуры**, мягкие тени;
- кнопки в стиле **fill-button**: залитые, скруглённые («пилюли»), hover — яркая бирюза;
- контентные блоки — **белые карточки** со скруглением и мягкой тенью;
- поле поиска — скруглённая «пилюля»; подменю — белые карточки; стрелки слайдеров — бирюзовые кружки.

- Визуально уже читается как «новый стиль», а не перекраска;
- Всё ещё один CSS-файл, разметка не тронута, риск невысокий;
- Минус: типографика (Tahoma, кегли) остаётся старой; шапка по компоновке — старая.

## Вариант 3 — «Полный скин» (максимальное приближение)

**Файл:** `demo/variant3-fullskin.css` (~260 строк)
**Демо:** `demo/variant3.html`

Всё из варианта 2 плюс:
- **типографика нового уровня**: PT Sans / PT Sans Caption (уже подключены на сайте), новые кегли и насыщенность заголовков;
- **перекомпоновка шапки средствами CSS**: светлый топбар (аналог `header-top-block`), бирюзовая зона с логотипом, **светлая плашка меню** с бирюзовым текстом (аналог `header-bottom-block`);
- новости — список с разделителями и приглушёнными датами вместо заливки при ховере;
- тёмно-бирюзовый футер (аналог `site-footer`).

- Максимально похоже на новый дизайн при нетронутом HTML;
- Минус: самый хрупкий из трёх — переопределений много, возможны каскадные конфликты на внутренних страницах; нужен полный регрессионный прогон (3–5 дней с тестированием).

## Сравнение

| | Вариант 1 | Вариант 2 | Вариант 3 |
|---|---|---|---|
| Что меняется | только цвета | цвета + форма компонентов | + типографика и компоновка шапки/футера |
| Похожесть на новый дизайн | ~40 % | ~75 % | ~90 % |
| Трудозатраты (оценка) | 1–2 дня | 2–4 дня | 3–5 дней + регресс |
| Риск сломать внутренние страницы | минимальный | низкий | средний |
| Откат | мгновенный | мгновенный | мгновенный |

**Рекомендация:** начать с **варианта 2** как оптимума «эффект/риск»: он уже даёт ощущение нового дизайна (плоские поверхности, карточки, fill-button), но не трогает типографику и компоновку, поэтому безопасен для сотен внутренних страниц. Вариант 3 — хороший второй этап после прогона на внутренних разделах. Вариант 1 — запасной, если сроки критичны.

## Ограничения подхода

- Часть зелёного «зашита» в **растровых картинках** (баннеры левой колонки, карта, логотипы) — CSS их не перекрасит, нужна замена графики;
- В контенте новостей встречаются **инлайн-стили** (`style="color: #006100"`) — переопределяются только через `!important` либо чисткой контента;
- Все три варианта — «скин»: семантика и новые блоки (pub-карточки, форма подписки, swiper) нового дизайна не появятся — это уже переделка шаблонов, а не «натяжка стиля».

## Подключение на сайте

```html
<link rel="stylesheet" href="/bitrix/templates/.default/css/redesign-variant2.css">
```

строкой **после** `custom.css`/`menu_drop.css` в шаблоне. Все файлы самодостаточны, внешних зависимостей нет.

## Как посмотреть демо

Скачать папку `demo/` целиком и открыть `variant1.html` / `variant2.html` / `variant3.html` в браузере (`base.html` — исходный старый вид для сравнения). Демо-страницы подтягивают стили и картинки действующего сайта, поверх — файл варианта.
