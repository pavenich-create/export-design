# Демо вариантов

Три CSS-скина нового оформления для старой структуры сайта. Подробное описание и сравнение — в файле `Варианты_переноса_дизайна.md` в корне ветки.

## Как посмотреть вариант на живой странице

1. Откройте сохранённую страницу `Главная_0.html` (старый дизайн) в браузере.
2. Через DevTools (Sources → Overrides, либо просто добавлением `<link>` в `<head>`) подключите один из файлов:
   - `variant1-palette.css` — только палитра;
   - `variant2-components.css` — палитра + компоненты (рекомендуется);
   - `variant3-fullskin.css` — полный скин.
3. Файл должен идти последним среди стилей, внешних зависимостей нет.

Либо в шаблоне сайта добавьте после `custom.css`/`menu_drop.css`:

```html
<link rel="stylesheet" href="/bitrix/templates/.default/css/redesign-variant2.css">
```
